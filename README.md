## 🧠 About This Repository

This repository contains a collection of modules and real-world implementations developed to master the modern Java ecosystem. It goes beyond fundamental programming to focus on clean code, software architecture, and industry-standard practices required for Senior Backend development.

## 🛠️ Tech Stack & Key Concepts

- **Core & Modern Java:** Advanced Generics, Records, Functional Programming (Lambdas, Streams API), and robust null-safety with `Optional<T>`.
- **Concurrency & Multithreading:** Deep dive into `Thread`, `Runnable`, `ExecutorService`, `Callable`, and parallel processing.
- **Reactive Programming:** Asynchronous data streams and event-driven architecture using **RxJava** (Observables, Observers, and Schedulers).
- **Database & Persistence:** Advanced SQL, manual JDBC connections, Connection Pooling (HikariCP), DAO Pattern, and strict Transaction Management.
- **Software Architecture:** Custom MVC implementation, Clean Architecture principles, and practical application of **GoF Design Patterns** (Strategy, Singleton, Observer, Decorator, Builder, Command, Factory Method).
- **Frameworks & Tooling:** Spring Boot, Thymeleaf, Docker, Lombok, Gson, and Jackson.

## 📂 Project Structure

The repository is organized by learning modules to keep the concepts isolated and easy to navigate:

- `01-advanced-generics/` - Reusable data structures and type safety.
- `02-mvc-and-lombok/` - Custom MVC architecture and boilerplate reduction.
- `03-functional-programming/` - Deep dive into Streams, Lambdas, and interfaces.
- `04-optional-api/` - Advanced null-handling strategies.
- `05-concurrency-and-threads/` - Multithreading and task scheduling.
- `06-reactive-programming-rxjava/` - Asynchronous flows and event combinations.
- `07-sql-and-jdbc-persistence/` - Relational databases, connection pools, and transactions.
- `08-gof-design-patterns/` - Implementation of standard industry patterns.
- `09-java-time-api/` - Modern date and time handling.
- `10-spring-boot-intro/` - Web applications and cloud deployment.

## 🚀 Getting Started

### Prerequisites
- **JDK 21** (or higher)
- **Maven**
- **Docker** & **Docker Compose** (for database instances)
- **IntelliJ IDEA** (Recommended)

### Running the Modules
Each folder acts as an independent module. Navigate to the specific directory to find its respective `Main.java` class or Spring Boot application runner.
